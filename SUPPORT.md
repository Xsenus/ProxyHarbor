# Поддержка ProxyHarbor

## Где задавать вопросы

- Ошибка продукта: создайте GitHub issue по шаблону bug report.
- Новый публичный feed: используйте шаблон source request и приложите URL, протокол, лицензию/условия и результат локального аудита.
- Вопрос по эксплуатации: сначала проверьте [документацию](docs/README.md), затем создайте issue с версией, режимом запуска и обезличенными логами.
- Уязвимость или утечка секрета: не создавайте публичный issue; следуйте [SECURITY.md](SECURITY.md).

Проект пока не гарантирует SLA или индивидуальную бесплатную поддержку. Maintainers отвечают по мере возможности.

## Что приложить к отчёту

- Git commit или release version;
- ОС, архитектуру, Docker/.NET/Node версии;
- точную команду и ожидаемое/фактическое поведение;
- минимальный воспроизводимый пример;
- релевантные логи без ключей, токенов, connection strings, IP-списков и backup-содержимого.

Не публикуйте `.env`, secret files, реальные admin/Telegram credentials, production dump или собранные proxy lists.
